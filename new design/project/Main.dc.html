Design proposal · [DATE]

StaffWare, moved from Access to a modern web app

The same jobs, lots, billing, payroll and inventory rules your team uses today — on clear, searchable screens that run in any browser. Each row of this canvas shows an existing Access screen next to its new web version.

TODAY — ACCESS

Powerful, but hard to learn

  • 18 switchboards with hundreds of grey buttons
  • Letter codes (A, B, E F K…) say which filters each report needs
  • Reports only open as fixed print previews
  • Needs Microsoft Access on a 1920×1080 office PC
PROPOSED — WEB

Same rules, easier screens

  • One menu grouped by area, plus a global search
  • Filters appear only for the report you choose
  • Results on screen: sort, drill in, export, then print
  • Guided steps for billing, payroll and inventory counts
WHAT STAYS THE SAME

Your data and your logins

  • Same SQL Server database — no data migration
  • Same LoginUsers accounts and module permissions
  • Business rules follow the existing Access queries and macros
  • Access can keep running side by side during roll-out
